# LifePPF — Life Past Present Futur

Une vie entière, une année à la fois. Simulateur de vie en texte par Aze Le Onze. Version 0.3.0.

**Jouer : https://azeleonze.github.io/lifeppf/**

- Marche sur PC et sur téléphone, s'installe comme une application et fonctionne hors ligne.
- Tes choix d'enfant forgent ton caractère, et ton caractère écrit la suite : école, Parcoursup, métiers, amours, enfants.
- Des centaines de happenings absurdes, un journal daté, cinéma, jeux vidéo, livres, festivals.
- Niveaux de compte, succès, cimetière de tes anciennes vies, continuer avec un de tes enfants.

Les notes de chaque version sont dans [CHANGELOG.md](CHANGELOG.md).
